### SI-ABSEN: Enterprise School Management & Smart Attendance System
  Aplikasi web berkelas enterprise (SaaS-ready) untuk digitalisasi total operasional sekolah. Menggabungkan
  sistem absensi pintar (QR, Fingerprint, GPS), manajemen akademik, payroll (penggajian), dan sistem notifikasi
  WhatsApp otomatis. Dibangun dengan arsitektur REST API Laravel yang tangguh dan panel antarmuka Next.js yang
  sangat elegan dan responsif.
